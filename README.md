# UniGuide AI

AI-powered university information and student assistance system for COMSATS University Abbottabad.

## Project Overview

UniGuide AI uses Retrieval-Augmented Generation (RAG) to provide students with university-specific information from a curated knowledge base.

## Features

- RAG-based question answering
- Semantic document retrieval
- Chroma vector database
- OpenAI LLM
- FastAPI backend
- Flutter frontend
- Conversation history
- Official source references
- English, Urdu and Roman Urdu query support

## Technology Stack

- Flutter
- Python
- FastAPI
- LangChain
- Chroma
- Sentence Transformers
- OpenAI API

## Knowledge Base

The system uses a curated collection of COMSATS Abbottabad university information covering:

- Admissions
- Fees
- Programs
- Scholarships
- Hostel
- Transport
- Student Affairs
- FAQs
- Rules and Conduct
- Contacts and Offices
